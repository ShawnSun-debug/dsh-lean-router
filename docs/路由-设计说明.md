# 思考链路由层设计说明（票 05 / dsh-lean-router）

> 台账版本 v1 · taskId=t5。本文档是交付物的设计依据与宿主接缝证据汇总。
> 上游 `dsh-routing-suite`（DSH<0.2.0 旧线）只取思想与实测结论，不搬代码；宿主事件形状以本机 0.2.2-rc.5 node_modules 实读为准。

## 1. 目标与思想来源

思考链路由层把「模型 persona 轴非连续、分相变」的实测特性量化为三个稳定行为带，
在会话首轮捕获真实用户消息分类定带，并以缓存友好的近场引导维持带内纪律：

| 带 | 语义 | 工具面 | persona 风格 |
|---|---|---|---|
| spec | 先读后改（inspect-and-plan） | 窄（读向） | 计划-集体 |
| react | 直接产出（hands-on production） | 宽（写向） | 执行者 |
| weak | 模型自分类（self-routed） | 窄 | neutral + classify few-shot |

关键实测结论（上游 preset/README.md、docs/STANDARD-PLAN.md，V4.1 Flash）：

- persona 轴三带量化：spec 0-0.19 / react 0.5-1.0 稳定；mixed 0.2-0.49 是转换陷阱，永不自动选中。
- Flash 阈值型最优 = neutral + classify few-shot + 三锚（回顾/收敛/反跑题）：路由 96%、单任务完成 100%、反稀释。
- 模型不能自路由：weak persona + few-shot 分类指令是唯一内路由窗口（区分度 +2.3..+3.3，lean 不翻转）。
- 首轮分类真实生效依赖 `agent/inbox/claimed` 在系统提示装配前捕获（上游 issue #13）。
- 近场引导必须与用户消息同请求注入且不加第二次 API 调用（上游 issue #34/#36/#55，此前 2× 费用）。
- 行为路径承诺：带在首轮锁定；中途换 persona 使整个前缀缓存失效（P6 尾部 persona 无效）。
- 长程任务勤勉度衰减真实存在（上游 graded/STUDY 懈怠观测），对抗机制按轮距注入自检。

## 4. 注入通道论证：为什么是 dynamic context 而不是 pre-step append

契约要求「近场引导固定文本（缓存友好：不改写历史、不加 API 轮次）」。宿主有三条候选通道：

1. **pre-step durable append**（time-context 样板，`@deepseek-ai/dsh-time-context/lib/index.js:265-281`）：
   消息随 decision.messages durable append（agent-loop :878）→ 当前请求即包含，但**每步都写历史**，
   重复引导文本会累积膨胀；须自建节流，且语义是「durable 注入」，与「不改写历史」冲突。
2. **runtime-context 消息**：pre-step 返回 `source.kind === "runtime-context"` 的消息会被宿主跳过不落盘（:873），
   但也不进请求（请求消息来自 surface，:1091）——死通道。
3. **dynamic context（采用）**：`ctx.systemPrompt.context()` 的 text 函数按 agent 路由状态返回固定文本；
   状态不变 → `deepEqualJson` 相等 → 零写入（:341）；改档/勤勉轮 → 文本变化 → 宿主 append 一条新
   system-reminder（supersession 管理，append-only 不改写既有历史）→ durable surface → 下一次请求起包含。
   同带每轮文本恒定 = 前缀缓存稳定；变化频率 = 改档次数 + 勤勉轮距，最小化追加。

## 5. 状态与生命周期

- 路由状态存 **agent 会话作用域 WeakMap**（keyed by agent），不污染全局（约束 4）。
- 捕获只认 `source.kind === 'user'`；插件注入/工具消息不触发（约束 5）。
- 显式 `[router] band=<spec|react|weak|auto>[ task=<...>]]` 指令优先（人在回路）；`auto` 清除覆盖回退自动。
- 无指令且未路由时 `classifyTask` 关键词分类；已路由后关键词**不改带**（路径承诺），仅显式指令与 `/band` 可改。
- 子代理/fork 继承会话（`agent.session.parentSession` 存在）默认跳过路由（`skipInherited: true`，可关）。
- 勤勉自检 `diligenceEvery`（默认 10，0 关闭）：轮次号入文，非勤勉轮文本不变、零写入。
- 任务回显：显式 task 文本编进引导文本（上游 v1.19.1 实测：模型每轮看清在为什么事工作）。

## 6. persona 拼接点（约束 4：禁直接改 persona）

`ROUTER_PROMPT`（lib/router.js 导出常量）是首轮 [router] 分类指令文本，**由 master 拼进**预设 persona 插件行的
`config.suffix` 文本尾部（票 03 lean 纪律在前、ROUTER_PROMPT 在后，换行续接）：

- 该 suffix 由 `@deepseek-ai/dsh-persona` 渲染为 `deployment:persona-suffix` 节（order 10200）。
- 各带 `BANDS[*].personaText` 为 persona 变体文本常量，供 master 在 suffix 里按带选择（或全部常驻由路由引导分流）。
