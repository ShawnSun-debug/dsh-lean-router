# 审计面板与落盘 - 设计说明（票 07）

本文件是票 07 的交付物之一：审计流 JSONL 落盘（sink）、命中统计与 /lean-audit 命令、手动权重配置、ui/go.json 面板卡片（双入口）的设计与验收依据。
约束以交接契约台账为准；本文件不覆盖台账，只做落点说明。行号引用来自本仓库当前实读。

## 1. 落盘（约束台账 2）：路径 / 轮转 / 懒建 / 错误策略

- **默认路径**：`<homedir>/.dsh/lean-router/audit.jsonl`（lib/audit-sink.js:20 `defaultAuditPath()`）。
- **patch 行可配**：`config.auditPath` → 插件 options（lib/router.js:159 `audit: cfg.audit === true`；auditPath 校验在 resolveOptions）。patch 行示例与改动清单见 §9（本票不改 frag 文件，由 master 集成）。
- **追加写**：每条决策一行 JSON，行尾换行，`appendFileSync` 逐条追加（不持有 fd；订阅回调是同步的，见 §2）。
- **轮转**：单文件达到 5MB（lib/audit-sink.js:17 `DEFAULT_AUDIT_MAX_BYTES = 5 * 1024 * 1024`）先整体改名 `audit.jsonl.1` 再追加（lib/audit-sink.js:51 `rotateIfNeeded`；覆盖旧 .1，单代轮转，无第 N 代）。
- **目录懒建**：首次写入前 `mkdirSync(dirname, { recursive: true })` 一次；写入失败会复位懒建标记、下次重试。
- **错误策略**：审计永不破坏门控管线——任何写失败（JSON 序列化、mkdir、append、rename）只计入 `sink.stats().errors`，不抛错（lib/audit-sink.js entry/rotate 两处 try/catch）。
- **可观测**：`createAuditSink(...).stats()` = `{ lines, bytes, rotations, errors }`（累计口径）。

## 2. 决策流接线图（skillgate 决策流接 sink；加法扩展）

```

        |  显式传入 audit = getAuditChannel()（lib/skillgate.js:291 懒建共享单例）
        v
createAuditChannel.push(entry)                                 内存环形缓冲（容量 256）+ 盖章 { seq }
        |  subscribe(fn)
        v
wireAuditSink(channel, { path })  （lib/audit-sink.js:101）      sink.entry(stamped) = 订阅函数
        |  appendFileSync（懒建目录 -> 轮转判定 -> 追加）
        v
```

要点：

- **共享通道是唯一接缝**：master 集成的近场调用（每轮 round()）与 lib/router.js apply 的 audit 行（挂 sink）都用 `getAuditChannel()` 对齐同一条决策流；显式传入的通道优先于单例，round() 缺省不推送（既有断言零影响，test/skillgate.test.mjs 不改仍绿）。
- **默认关**：`audit: true` 才挂 sink（lib/router.js:159）；关闭 = 零行为变化。真实落盘由 master 在 patch 行开启（§9）。
- **channel 与 sink 均纯 node**，测试全部用临时目录（acceptance 5），绝不写真实 `~/.dsh` 路径。

## 3. 审计条目格式（v=1；lib/skillgate.js:329 起）

每行一条 `skillgate-round` 记录（通道盖章后多出 `seq` 字段）：

```
seq      通道盖章序号（wireAuditSink 落盘行新增；重放排序/去重用）
v / ts / kind / turn / task{band,complex,head<=120} / config{autoScore,hintScore,tokenBudget,charsPerToken}
dsActive / scores[31 行全量 {name,score,signals{category{band,scene,points,complex},keywords},model,user}]
decision{band,complex,auto[],hint[],arbitrations[],degradations[],estTokens,budgetTokens,mode:"fallback-cached-list"}
estimateText  本轮近场渲染文本
```

`entry.config` 的四键形状是既有断言面（test/skillgate.test.mjs deepEqual），本票未增删该形状；`seq` 只出现在落盘行（`round()` 返回的 auditEntry 不变）。

**样例行**（真实管线生成：31 技能全打分；react 带；temp 目录；行 8883B，全文过长截断展示）：

```
{"seq":1,"v":1,"ts":"2026-11-21T06:15:15.368Z","kind":"skillgate-round","turn":1,"task":{"band":"react","complex":false,"head":"帮我开发一个贪吃蛇游戏网页，写一个可玩的版本"},"config":{"autoScore":2,"hintScore":1,"tokenBudget":8000,"charsPerToken":4},"dsActive":[],"scores":[{"name":"ask-matt","score":0, ... 31 行 ... }],"decision":{"band":"react","complex":false,"auto":["code-review","codebase-design","diagnosing-bugs","domain-modeling","implement","improve-codebase-architecture","setup-ts-deep-modules","tdd"],"hint":[9 项],"arbitrations":[],"degradations":[],"estTokens":810,"budgetTokens":8000,"mode":"fallback-cached-list"},"estimateText":"Skill gate (turn 1, band=react): ..."}
```

同文件第 2 轮样例（spec 带 + dsActive=["ds-tdd","ds-mode"]）：裁决把 engineering 场景的全部 auto 降为 hint -> `auto:[]`、`hint:9` —— ds-* 裁决效果可审计。

行大小参考：31 全量 scores 约 8.9KB/行 -> 5MB 约 590 轮/文件，轮转足够。

## 4. 手动权重文件（约束台账 3）：assets/gating.weights.json

- **schema = resolveGateConfig 的可配子集**（lib/skillgate.js:363 `loadGateWeights` 读文件 -> `resolveGateConfig(partial)` 复用既有校验）：

```json
{
  "version": 1,
  "sceneMap":     { "react": {"engineering":2,"process":1}, "spec": {"engineering":2,"research":1}, "weak": {} },
  "complexBoost": { "engineering": 1 },
  "autoScore": 2,
  "hintScore": 1,
  "tokenBudget": 8000,
  "charsPerToken": 4
}
```

- `autoScore`（>= 阈值 -> auto 自动挂载）、`hintScore`（>= 阈值 -> hint 近场提示）、`tokenBudget`（软降线：注入估算 token 超过即软降）、`charsPerToken`、`sceneMap`（场景加分）、`complexBoost`（深度加成）。
- **缺省值 = 当前硬编码**：仓库内文件就是 DEFAULT_GATE_CONFIG 的值（test/audit-commands.test.mjs「包内权重文件」断言逐字段相等）。
- **缺失 -> 回退默认**：`loadGateWeights` 返回 `status:"default"`（正常态，非错误）。
- **损坏/非法 -> 回退默认并带原因**：JSON 损坏、version≠1、未知键、值非法 -> `status:"fallback"` + `error`（/lean-audit weights 显示原因并出黄条）。
- **只影响放行集合**：权重进 resolveGateConfig 产物（autoScore/hintScore/tokenBudget/sceneMap/complexBoost），只改 auto/hint 分档与软降线；invocation（model/user 矩阵语义）原样——arbitration 不在权重文件内（台账只授权场景加分/阈值/软降线三组）。
- **接线**：master 集成的每轮 round() 调用方在启动时 `await loadGateWeights()` 取 `weights.config` 传入；`/lean-audit weights` 视图用同一 loader 展示生效值与回退状态（双端一致，无独立内存态）。

## 5. 命中统计口径（约束台账 1）：技能 × 场景聚合

- **来源 = 审计流回放**：`readAuditEntries` 读当前 JSONL 文件（<=2000 条上限防异常大文件），**不新增内存态**。
- **聚合键**：技能名 × 场景（场景取自 `scores[].signals.category.scene`，来自矩阵 scenario）。
- **计数**（lib/audit-commands.js:134 `aggregateStats`）：
  - `rounds`：该技能出现在 scores 里的轮数（31 全打，默认=总轮数）；
  - `hits`：关键词信号命中（`signals.keywords` 非空）的轮数；
  - `auto` / `hint`：该轮 decision 放行档位命中（挂载）的轮数；
  - `degraded`：`decision.degradations` 命中（软降）的轮数。
- **轮转历史（.1）不并入统计**：口径 = 当前文件；跨文件统计由 master/面板层自行合并（如需，明说再扩）。
- **坏行**：回放跳过并计数，黄条提示（⚠ replay skipped N malformed line(s)）。

## 6. /lean-audit 命令（双入口之一）

注册在 lib/router.js:297（命令分发处加法接线，实现全在 lib/audit-commands.js:272）；数据源 = 回放，无 agent 依赖。

| 视图 | 内容 |
|---|---|
| `/lean-audit`（默认） | 黄条（如有）-> 最近 N=10 条**决策行**（如 #01 turn=3 band=react* auto=2 hint=5 tokens=1240/8000；* = complex）-> **token 对比**（最新一条：est 1240 / budget 8000 (charsPerToken=4)）-> **得分表折叠**（Top5 + /lean-audit scores 展开提示）-> **命中统计表** |
| `/lean-audit scores [N]` | **全量得分表**展开（最近 N 条，每条 31 行：name/score/tier/scene/命中词/m-u） |
| `/lean-audit stats [N]` | 仅命中统计表（含坏行黄条） |
| `/lean-audit weights` | 权重生效值 + 状态（loaded/default/fallback）+ 编辑提示 |

**黄条**（lib/audit-commands.js:178 `collectWarnings`；仅在有问题时出现，⚠ 开头）：单轮 estTokens > budgetTokens；有软降级；回放坏行；权重回退。四要素映射：决策行 -> `formatDecisionLine`、token 对比 -> `formatTokenLine`、得分表折叠 -> `renderScoreCollapsed`/`renderScoreTable`、黄条 -> `collectWarnings`。

## 9.3 已接线（票 t9，2026-11-21）

- **调用点**：`lib/router.js:301` 的 `agent/inbox/claimed` 钩子——仅 `message.source?.kind === 'user'` 时 `await gateRunner.capture(agent, messageText(message), turn)`（lib/router.js:310）；近场文本在 `ctx.systemPrompt.context` 求值时调 `gateRunner.hintFor(agent, band)`（lib/router.js:317-322，band 取自路由状态）。门控默认关：`cfg.hooks && cfg.gate` 才创建 runner（lib/router.js:295-298），关闭时 text 与现状逐字符一致。

- **dsActive 实现**：capture 内从宿主技能目录观察 `ds-` 前缀技能名（去重排序）存入 states，作为 `state.dsActive` 传给 `round(state, ...)`（gate-runner.js:122-129 区段）；仲裁在 skillgate.round 内按 DEFAULT_GATE_CONFIG 的 arbitration 表执行（engineering 场景 prefers ds-*，ds 活跃时 mattpocock 工程技能 auto→hint）。
- **权重热读**：`loadGateWeights(path)` 每轮 refresh 时读盘——改文件下一轮生效（test/gate-run.test.mjs:62-68 断言）；缺文件 → default 配置，非法 → 带原因回退。
- **审计落盘**：hintFor 每轮决策经共享通道 `getAuditChannel()` 推送（去重：同轮同决策只一条、新轮新条目，test/gate-run.test.mjs:95-108）；commands 行 `audit: true` 时挂 sink 落 JSONL。
- **hint 格式样例**（与 renderAdmission 逐行同构，仅头部省略轮次号）：

```text

- <name> [auto]: <description>

- <name>: <description>
```

- **零副作用锚点**：无 band / 无 taskText / 目录未就绪 / 权重未就绪 → hint 返回空串且不发审计（test/gate-run.test.mjs 末条断言）。
