# 工具遮蔽层接线说明（票 04 · toolface）

> 状态：t4 交付稿（master 验收前）。上游来源：dsh-codemode 0.3.x main f9758ec1061a9a0af4f1dfefbacc19c5987b11d1（version 0.3.0）。

## 1. 这一层做什么

lean-router 预设下的会话运行在 Code Mode：预设自身清单里的工具照常直接调用；
预设之外的工具（全局层 MCP 服务端与 bundle、agent 层工具集）不进模型上下文，
由插件自带的 code_run 程序传输按需发现并调用。四件套：

1. 发现工具 code_tools_list / code_tools_search / code_tools_describe / code_debug
   ——注册在预设作用域内的普通工具，只能从程序内部调用；
2. 程序传输 code_run（保留名 run_code 归 DSH 内建 PTC，注册表拒绝注册）；
3. 预设作用域的 ToolExecutor：describe() 把预设外工具从请求面遮蔽，
   execute() 在派发前拒绝模型直呼被遮蔽名并给自愈提示；
4. Code Mode 指令文本以 executor 的 tools:sdk 段提供（替代 DSH 自己的 SDK 段）。

注册表从未被改动：被遮蔽的工具仍可从程序内部经注册表公共 execute() 调用
（子调用 signal 打 Symbol.for('dsh-codemode.nested') 标记 + :ptc: 调用 id 双证）。

## 3. 缺依赖降级（stub 路径）

vendored 版去掉了上游对 @deepseek-ai/dsh-tool-executor-native 的顶层静态 import：

- loadNativeExecutorModule() 动态 import，在 apply() 里 setExecutor 之前完成
  （describe() 是同步签名，模块必须在挂载时可用）；
- 依赖缺失时（或测试显式注入）走 stub delegate：describe/execute 被真正调用
  即抛出引导安装错误（消息含包名与安装方式），模块加载与本包 import 不受影响；
- 执行管线不重写：policy/approval/around-dispatch/post-execute 全部由
  @deepseek-ai/dsh-tool-executor-native 的 NativeToolExecutor 承担，跨模块图驱动宿主
  注册表（宿主现装 0.2.2-rc.5，依赖区间 ^0.2.2-alpha.3 覆盖之）。

## 4. 直呼拒绝路径

executor.execute() 对批量内每个 call 判定：嵌套调用（标记 signal 或 :ptc: id）、
guard:false、传输名本身豁免；被遮蔽名在派发前整批拒绝，被拒调用给自愈提示
（引导先 tools.code_tools_search 再经 code_run 调用），同批被牵连的合法调用
各自拿到「单独重发」提示。拒绝发生在注册表管线之外、派发之前——遮蔽名不在
模型拿到的目录里，tools.guard()（管线内）拦不住它。

## 5. 预设接线（frag-toolface.patch.yml）

presets/base/frag-toolface.patch.yml 是顶层列表续项（"- id: preset-lean-router" 键级
override，形态对齐上游样本）。cordis patch override 是键级整体替换、预设行不是
group，无法向 plugins 数组增量插入，故本分片把 config.plugins 整快照重声明：
base 全部行原样保留 + 追加 toolface 行（name: 'dsh-lean-router/toolface'，config
显式写出全部默认值）。防漂移由 test/toolface-wiring.test.mjs 锁定（frag 行集合 =
base 行集合 + toolface）。

集成注意：票 03/05 若也需改 preset 行（persona suffix、加行）与本分片是同一接缝，
整键 override 后写者覆盖先写者；由 master 统一裁决（可把 toolface 行并入
presets/base/lean-router.patch.yml、本分片只留校验）。cordis.patch.yml 由
scripts/build-bundle.mjs 生成，master 已合入并通过 build --check 反向一致与 doctor。
